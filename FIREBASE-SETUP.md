# Firebase для «Парты» (5 минут)

Файл `app/google-services.json` уже лежит в проекте (проект Firebase из него).

1. **Authentication → Sign-in method**: включи **Email/Password**, **Google**, (по желанию) **Apple**.
2. **Firestore Database → Create database** (любой регион) → вкладка **Rules** → вставь содержимое `firestore.rules` → **Publish**.
3. **Project settings → Your apps → Android (com.school.hub) → Add fingerprint**:
   - SHA-1: `94:1F:DB:98:5C:8F:56:78:CE:64:F7:93:E2:C8:8B:53:B2:AB:12:24`
   - SHA-256: `1F:B0:89:27:2C:48:38:5A:CD:40:1D:E5:6B:35:17:CE:20:18:13:AA:5D:FA:C0:D4:F8:8B:72:CB:63:B1:FF:F7`
4. После шагов 1 и 3 **скачай google-services.json заново** и замени `app/google-services.json` — без этого кнопка «Войти через Google» напишет, что не настроено.
5. **Apple**: нужен платный Apple Developer ($99/год) — Services ID + ключ, вписать в Firebase → Apple. Без этого кнопка Apple покажет ошибку, остальное работает.

## Админы
- Всегда админы: почты из `Owners.kt` и `firestore.rules` (поменяй на свои в обоих местах).
- Других назначаешь в приложении: вкладка «Админ» → «Аккаунты» → «Сделать админом».

## Что где хранится
- `users/{uid}` — почта, имя, фамилия, роль, блокировка, устройство, версия. **Пароли — только в Firebase Auth в виде хеша, их не видит никто.**
- `banned/{почта}` — блокировки по почте (работают даже до регистрации).
- `stats/{устройство}` — статистика. Без интернета копится в очереди и уходит при подключении; по Bluetooth пересылается через телефоны одноклассников.

Бесплатного тарифа Spark хватает с большим запасом (50k чтений / 20k записей в день).
