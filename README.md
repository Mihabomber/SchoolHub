## Что умеет

| Раздел | Что внутри |
|---|---|
| **Учёба** | Шпаргалки (текст и фото, предметы, поиск, избранное), расписание со звонками и напоминаниями, домашка, оценки, фокус-таймер |
| **ИИ-помощник** | Локальные модели через llama.cpp (JNI). Работает без интернета. Фото в чат: зрение у моделей с mmproj, для остальных текст с фото распознаётся на телефоне |
| **Менеджер моделей** | Каталог моделей с размером и требованиями к памяти, загрузка, удаление |
| **Переводчик** | Офлайн-перевод текста и перевод с камеры, языковые пакеты скачиваются отдельно |
| **Игры 2.1 Games** | Больше 30 игр, в том числе 3D-куб, футбол и 2048. Все игры работают на своём движке 2.1 Games |
| **Обмен** | Синхронизация шпаргалок, расписания и домашки через интернет или без него (Bluetooth, Wi-Fi Direct через Nearby Connections) |
| **Аккаунты** | Вход по почте с подтверждением, Google или Apple. Пользовательское соглашение и отдельное согласие на обработку персональных данных |
| **Админка** | Статистика устройств, список аккаунтов, ограничение доступа, назначение администраторов. Видна только администраторам |

## Как работает без интернета

- Все данные хранятся на телефоне (Room). Сеть только догоняет изменения.
- Есть интернет: синхронизация при старте, при появлении сети и после каждой правки.
- Нет интернета: «Обмен → Начать обмен с классом». Телефоны одного класса находят друг друга, обмениваются снимками базы и пересылают новое дальше. Так изменения доходят до всех по цепочке.
- Конфликты решает последняя правка (Last-Writer-Wins по `updatedAt`). Удаления тоже расходятся.
- ИИ, распознавание текста, переводчик с пакетами и игры работают полностью офлайн.

## Скачать и установить

1. Открой [последний релиз](https://github.com/Mihabomber/SchoolHub/releases/latest).
2. Скачай `SchoolHub.apk` и установи. Нужен Android 8.0+ (arm64).
3. Новые версии подписаны тем же ключом и ставятся поверх старых. Данные сохраняются.

Сборки из ветки `v2.1-dev` лежат в артефактах на вкладке [Actions](https://github.com/Mihabomber/SchoolHub/actions).

## Сборка

### Через GitHub Actions

Каждый push в `main` или `v2.1-dev` запускает [Build APK](.github/workflows/build-apk.yml). Сборка пробует варианты по очереди:

| Шаг | Вариант |
|---|---|
| 1 | llama.cpp b8720 + зрение (Gemma 4) |
| 2 | llama.cpp b8720 без зрения |
| 3 | llama.cpp b6550 + зрение |
| 4 | без ИИ-движка |

Ошибки компиляции видны прямо в аннотациях запуска. С ветки `main` APK публикуется в Releases.

Секреты репозитория (все необязательны):

| Секрет | Зачем |
|---|---|
| `SIGNING_KEYSTORE_B64` | Ключ подписи в base64. Без него берётся ключ из истории `main` |
| `SIGNING_STORE_PASSWORD`, `SIGNING_KEY_ALIAS`, `SIGNING_KEY_PASSWORD` | Пароли и алиас ключа |
| `GOOGLE_SERVICES_JSON` | Содержимое `google-services.json`. Без него вход в аккаунт не работает |

### Локально

Android Studio Koala+ и JDK 17, или Gradle 8.9:

```bash
gradle assembleDebug -PwithLlama=true -PwithVision=true -PllamaTag=b8720
# без ИИ-движка, быстрее:
gradle assembleDebug -PwithLlama=false
```

Для подписи задай переменные окружения `SIGNING_STORE_PASSWORD`, `SIGNING_KEY_ALIAS`, `SIGNING_KEY_PASSWORD` и положи ключ в `app/schoolhub.jks`.

### Сервер (необязательно)

`server/index.js`: Node 18+, без зависимостей.

```bash
cd server && node index.js     # порт 8080 или $PORT
```

Можно развернуть на Render, Railway, Fly.io или на ПК в школьной сети. Адрес указывается в приложении: «Обмен → Адрес сервера класса».

## Приватность

- При регистрации пользователь принимает соглашение и отдельно даёт согласие на обработку персональных данных (152-ФЗ). Тексты открываются прямо на экране входа.
- Приложение собирает только то, что указано в согласии: почта, имя, класс, модель устройства, версия приложения, счётчики использования.
- Приложение не собирает фотографии, переписки, содержимое чатов с ИИ, файлы и пароли.
- Удалить аккаунт и данные: написать на почту, указанную в согласии.

## Что нового в 2.1

- Аккаунты и админка на Firebase: почта с подтверждением, Google, Apple.
- Соглашение и согласие на обработку ПД при регистрации. Проверка имени мягче, без угроз блокировкой.
- Безопасные миграции базы: данные не теряются при обновлении.
- Подпись APK из секретов, ключ убран из дерева проекта.
- ИИ: остановка генерации прерывает работу модели сразу, контекст не переполняется.
- Больше 30 игр в 2.1 Games.
