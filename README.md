## 📦 Как получить APK (GitHub Actions)
1. Создай на GitHub **пустой** репозиторий, например `SchoolHub`.
2. Загрузи туда **содержимое** этой папки (Add file → Upload files, перетащи все файлы и папки).
   ⚠️ Проверь, что загрузилась скрытая папка `.github/workflows/`. Если нет — создай
   файл `.github/workflows/build-apk.yml` через «Add file → Create new file» и вставь содержимое.
3. Открой вкладку **Actions** — сборка стартует сама (≈5–8 минут).
4. Готовый APK появится в **Releases**. Постоянная ссылка на свежую сборку:
   `https://github.com/<логин>/<репо>/releases/latest/download/SchoolHub.apk`

## 🔄 Как работает обмен шпаргалками
* **Offline-first**: всё хранится в Room на телефоне; сеть только догоняет.
* **Есть интернет и сервер** → автосинхронизация при старте, при появлении сети и после каждой правки.
* **Нет интернета** → «Обмен → Начать обмен с классом». Google Nearby Connections сам выбирает
  Bluetooth, BLE, Wi-Fi Direct или локальную сеть. Телефоны одного класса (одинаковый **код класса**)
  находят друг друга, обмениваются снимками базы и **пересылают новое дальше** — шпаргалка
  доходит до всех по цепочке.
* Конфликты: побеждает последняя правка (Last-Writer-Wins по `updatedAt`); удаление тоже распространяется.
* Полученное по Bluetooth потом само уходит на сервер, когда появится интернет.

### Сервер (необязательно)
`server/index.js` — Node 18+, без зависимостей:
```bash
cd server && node index.js     # слушает :8080 (или $PORT)
```
Можно бесплатно развернуть на Render/Railway/Fly.io или на ПК в школьной сети.
Адрес указывается в приложении: «Обмен → Адрес сервера класса».
